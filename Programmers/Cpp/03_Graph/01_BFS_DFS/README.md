### L3 네트워크

- 연결 요소의 개수는 방문하지 않은 정점에서 BFS/DFS를 새로 시작하는 횟수로 센다.
- BFS는 시작 정점과 이웃 정점을 큐에 넣기 전에 방문 표시해야 중복 삽입을 막는다. 꺼낼 때만 표시하면 대기 중인 정점이 반복 삽입되어 탐색 비용과 큐 크기가 크게 증가할 수 있다.
- 인접 행렬 BFS는 각 정점의 행을 한 번씩 확인하므로 시간 O(N^2), 방문 배열과 큐의 보조 공간 O(N)이다. 입력 행렬을 값으로 전달할 때 발생하는 복사 공간 O(N^2)는 별도로 고려한다.

## 주요 개념 요약

### BFS 방문 처리와 연결 요소

- 방문 표시 시점과 연결 요소 세기는 위의 `L3 네트워크` 학습 노트를 참고한다. [예제](./L3_네트워크.cpp)

### 동일한 이동 비용의 격자 최단거리

- 모든 이동 비용이 같으면 BFS의 첫 방문 거리가 최단거리다. 거리 배열의 미방문 값을 -1로 두면 방문 여부도 함께 관리할 수 있다.
- 이동 횟수는 시작 거리 0, 지나간 칸 수는 시작 거리 1로 센다. 목적지를 큐에서 꺼내면 즉시 반환하고, 도착하지 못하면 -1을 반환한다.
- N행 M열에서 네 방향을 확인하는 BFS는 시간 O(NM), 거리 배열과 큐의 보조 공간 O(NM)이다. 입력 맵과 값 전달 복사 공간은 별도로 고려한다. [예제](./L2_게임맵최단거리.cpp)

### 트리의 간선 제거와 연결 요소 크기

- 트리는 간선 하나를 제거하면 정확히 두 연결 요소로 나뉜다. 한쪽 크기 s만 BFS로 구하면 나머지는 `N-s`, 차이는 `abs(N-2*s)`이다. 일반 그래프에서는 간선을 제거해도 연결이 유지될 수 있으므로 트리 조건을 확인한다. 예: [전력망을 둘로 나누기](./L2_전력망을둘로나누기.cpp).
- 시작점도 큐에 넣기 전에 방문 표시한다. 시작점을 이미 1개로 센 상태에서 방문 표시를 빼먹으면, 이웃이 시작점을 재발견해 크기를 중복 계산한다.
- 무방향 간선을 제외할 때는 양방향 모두 건너뛴다. 탐색 중 해당 간선을 무시하면 그래프 삭제·복원 없이 각 후보를 독립적으로 평가할 수 있다.
- 간선 N-1개인 트리에서 인접 리스트 BFS는 `O(N)`, 인접 행렬 BFS는 `O(N²)`이다. 모든 간선 절단을 검사하면 각각 `O(N²)`, `O(N³)`이며 그래프 저장 공간도 각각 `O(N)`, `O(N²)`이다.
- 더 큰 트리에서는 DFS 한 번으로 서브트리 크기를 구해 각 부모 간선의 분할 차이를 평가하면 시간·공간 `O(N)`으로 줄일 수 있다.
