# Queue (큐)

선입선출(FIFO) 구조 문제.

## 📝 학습 노트

> 코드 리뷰 시 핵심 takeaway가 아래에 추가됩니다.

### L2 기능개발

- 완료 일수는 `(남은 작업량 + 속도 - 1) / 속도`로 올림 계산한다.
- 배포 순서가 고정되어 있으면 앞 기능들의 가장 늦은 완료일을 기준으로 묶는다. 배열을 순회하면 별도의 큐 없이 시간 O(n), 결과와 입력 복사를 제외한 보조 공간 O(1)로 처리할 수 있다.
- `answer.back()`에 현재 묶음의 개수를 직접 기록하면 별도의 카운터와 마지막 묶음 추가 처리를 줄일 수 있다. 빈 벡터에 `back()`을 호출하지 않도록 먼저 확인한다.
