## 주요 개념 요약

### 누적 최적값과 경계 처리

- 각 칸까지 도달하는 경로의 최댓값을 상태로 정의하면 현재 값에 가능한 부모 상태의 최댓값을 더한다. 가장자리는 부모가 하나뿐이므로 따로 처리한다.
- 높이 N인 삼각형은 O(N^2)개의 칸을 한 번씩 갱신한다. 아래에서 위로 계산하면 항상 두 자식을 참조할 수 있어 경계 분기를 줄일 수 있다.
- 예제: [L3 정수 삼각형](./L3_정수삼각형.cpp).

### 입력 사본 재사용과 공간 계산

- 값으로 받은 2차원 벡터를 DP 저장소로 쓰면 별도 보조 공간은 O(1)이지만, 인자 복사 공간까지 포함하면 O(N^2)이다. 호출자의 입력은 변경되지 않는다.
- 1차원 DP로 이전 행만 보관하면 보조 공간은 O(N)이다. 위에서 아래로 계산할 때 오른쪽부터 갱신해야 이전 행의 필요한 값을 덮어쓰지 않는다. 값 전달 인자의 복사 공간은 별도로 계산한다.
- 비어 있지 않은 범위의 최댓값은 `*max_element(begin, end)`로 구한다. 초깃값을 0으로 두는 직접 탐색은 음수가 허용되는 문제에서 주의한다.
