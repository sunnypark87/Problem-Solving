# Sort (정렬)

정렬 알고리즘 및 정렬을 활용하는 문제.

## 📝 학습 노트

> 이 디렉터리의 문제를 풀면서 얻은 인사이트가 누적됩니다.
> 코드 리뷰 시 핵심 takeaway가 아래에 추가됩니다.

### L2 가장 큰 수

- 숫자의 크기 대신 두 문자열을 이어 붙인 `a + b`와 `b + a`를 비교해 정렬한다. 두 숫자의 자리를 바꿨을 때 전체 결과의 크기가 어떻게 달라지는지를 직접 비교하는 기준이다.
- 모든 원소가 0이면 이어 붙인 결과가 `"000..."`이 된다. 정렬 후 첫 원소가 `"0"`이면 `"0"` 하나만 반환한다.
- 이 문제는 원소가 최대 1,000이라 두 원소를 정수로 이어 붙여도 `int` 범위 안이다. 다만 문자열 비교가 자릿수 계산과 `pow`를 줄여 정렬 기준을 더 분명히 보여 준다.
- 정수 연결로 비교할 때 자릿수는 한 자리 수와 `0`도 `1`부터 시작해야 한다. 최댓값을 만들려면 `a·10^digits(b)+b > b·10^digits(a)+a`일 때 `a`를 앞에 둔다. 자릿수의 시작값과 부등호 방향을 각각 확인한다.

### L1 K번째수

- 문제의 구간 `[i, j]`는 1부터 세는 양끝 포함 구간이다. C++ 반복자 범위는 끝을 포함하지 않으므로 `vector<int>(array.begin() + i - 1, array.begin() + j)`로 복사한다.
- 구간 길이를 `m`이라 하면 복사에 `O(m)`, 정렬에 `O(m log m)`이 든다. 이 문제는 배열 길이가 최대 100이므로 전체 정렬이 간단하고 충분하다. 값 하나만 필요해 더 큰 입력에서 성능이 중요하다면 `nth_element`도 고려할 수 있다.

### L2 H-Index

- H-Index는 논문 수 `n`을 넘을 수 없다. 인용 횟수를 내림차순 정렬하면 `i`번째 논문이 `i + 1`회 이상 인용됐는지만 확인해 답을 갱신할 수 있다. 정렬에 `O(n log n)`, 순회에 `O(n)`이 든다.
- 인덱스로 원소를 읽기 전에 `i < n`을 먼저 검사한다. C++의 `&&`는 왼쪽부터 평가하므로 조건 순서가 바뀌면 범위 밖 접근이 생길 수 있다.
- `vector<int>`를 값으로 받은 함수에서는 매개변수 자체를 정렬할 수 있다. 같은 내용을 다시 복사한 벡터를 만들 필요가 없다.
