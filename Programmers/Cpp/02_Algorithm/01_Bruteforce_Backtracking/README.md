# Bruteforce / Backtracking (브루트포스 / 백트래킹)

완전 탐색과 백트래킹.

## 📝 학습 노트

> 코드 리뷰 시 핵심 takeaway가 아래에 추가됩니다.

### L1 최소직사각형

- 각 명함의 긴 변을 같은 축, 짧은 변을 다른 축에 맞추면 회전 조합을 나열하지 않아도 된다. 필요한 지갑 넓이는 `max(긴 변) * max(짧은 변)`이며, 모든 명함을 한 번씩 보므로 `O(n)`이다.
- 읽기만 하는 내부 `vector<int>`는 `for (const auto& size : sizes)`로 순회하면 매번 복사하지 않는다. `max`와 `min`으로 두 변을 정규화하면 가로·세로가 뒤집힌 경우의 중복 분기를 줄일 수 있다.

### L2 타겟넘버

- 숫자마다 `+` / `-`를 선택하는 DFS는 시간 `O(2^N)`, 재귀 스택 공간 `O(N)`이다. 총 호출 수와 동시에 유지되는 호출 수는 다르므로, 호출마다 작은 값을 복사해도 공간이 `O(2^N)`으로 누적되지는 않는다.
- 읽기 전용의 큰 객체는 `const vector<int>&`로 복사를 피하고, 작은 `int`는 값으로 전달하는 것이 자연스럽다. 참조도 원본에 접근할 정보가 필요하므로 항상 메모리를 절약하지는 않는다. `const int&`는 참조를 통한 수정만 막으며, 다른 경로로 원본이 바뀌면 읽는 값도 달라질 수 있다.
- DFS 반환값은 “현재 상태에서 찾은 답”으로 정의한다. 경우의 수는 종료 시 성공 `1`, 실패 `0`을 반환하고 자식 결과를 더한다. 처음에는 `plusWays`, `minusWays`처럼 결과를 변수에 받은 뒤 합치면 이해하기 쉽다. 가능 여부는 OR, 최댓값은 `max`로 결합한다.
- `countTargetWays`처럼 함수의 목적을 드러내는 이름을 쓰면 반환값의 의미가 명확해진다. 참조로 정답을 누적하는 방식도 올바르지만, 반환 방식은 외부 상태를 수정하지 않고 각 호출의 결과를 조합할 수 있다.

## 주요 개념 요약

### 반복 패턴과 동점 처리

- 길이 L인 패턴은 `pattern[i % L]`로 반복 구간을 조회한다. 사람 수와 패턴 길이가 고정이면 N개 입력을 비교하는 시간은 `O(N)`, 점수와 패턴의 보조 공간은 `O(1)`이다.
- 최고 점수를 구한 뒤 번호가 작은 순서로 같은 점수의 사람을 추가하면 동점자를 빠짐없이 오름차순으로 반환하므로 정렬이 필요 없다. 최고 점수가 0인 경우도 포함한다.
- `vector` 값 전달은 lvalue 인자로 호출할 때 복사를 만든다. 보조 공간과 입력 복사 공간을 구분하고, 프로그래머스의 제출용 함수 시그니처는 유지한다. 예: [모의고사](./L1_모의고사.cpp).
- 회전 정규화와 DFS의 분기·반환값·참조 전달은 위의 기존 학습 노트를 참고한다.

### 선형 탐색의 효율성과 대안 비교

- 모든 입력을 비교해야 점수를 정확히 계산할 수 있다면 선형 탐색이 적절하다. 고정된 K명의 패턴을 비교하는 비용은 `O(KN)`이며, K가 상수이면 `O(N)`이다. [모의고사](./L1_모의고사.cpp)는 최대 10,000문제에 30,000번의 정답 비교가 필요하다.
- 입력별 순회와 사람별 순회는 같은 비교를 수행한다. 사람별 순회는 인원 증가에 대응하기 쉽고, 입력별 순회는 각 정답을 읽으며 점수를 함께 갱신하기 쉽다.
- 나머지 연산 대신 순환 인덱스를 사용할 수 있지만 복잡도는 같고 경계 분기와 상태 관리가 추가된다. 고정 배열의 동적 할당 절감도 상수 비용 개선이며, 실제 속도 우위는 측정 없이 단정하지 않는다.
