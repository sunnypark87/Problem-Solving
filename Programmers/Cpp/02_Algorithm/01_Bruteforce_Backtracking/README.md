# Bruteforce / Backtracking (브루트포스 / 백트래킹)

완전 탐색과 백트래킹.

### L1 최소직사각형

- 각 명함의 긴 변을 같은 축, 짧은 변을 다른 축에 맞추면 회전 조합을 나열하지 않아도 된다. 필요한 지갑 넓이는 `max(긴 변) * max(짧은 변)`이며, 모든 명함을 한 번씩 보므로 `O(n)`이다.
- 읽기만 하는 내부 `vector<int>`는 `for (const auto& size : sizes)`로 순회하면 매번 복사하지 않는다. `max`와 `min`으로 두 변을 정규화하면 가로·세로가 뒤집힌 경우의 중복 분기를 줄일 수 있다.

### L2 타겟넘버

- 숫자마다 `+` / `-`를 선택하는 DFS는 시간 `O(2^N)`, 재귀 스택 공간 `O(N)`이다. 총 호출 수와 동시에 유지되는 호출 수는 다르므로, 호출마다 작은 값을 복사해도 공간이 `O(2^N)`으로 누적되지는 않는다.
- 읽기 전용의 큰 객체는 `const vector<int>&`로 복사를 피하고, 작은 `int`는 값으로 전달하는 것이 자연스럽다. 참조도 원본에 접근할 정보가 필요하므로 항상 메모리를 절약하지는 않는다. `const int&`는 참조를 통한 수정만 막으며, 다른 경로로 원본이 바뀌면 읽는 값도 달라질 수 있다.
- DFS 반환값은 “현재 상태에서 찾은 답”으로 정의한다. 경우의 수는 종료 시 성공 `1`, 실패 `0`을 반환하고 자식 결과를 더한다. 처음에는 `plusWays`, `minusWays`처럼 결과를 변수에 받은 뒤 합치면 이해하기 쉽다. 가능 여부는 OR, 최댓값은 `max`로 결합한다.
- `countTargetWays`처럼 함수의 목적을 드러내는 이름을 쓰면 반환값의 의미가 명확해진다. 참조로 정답을 누적하는 방식도 올바르지만, 반환 방식은 외부 상태를 수정하지 않고 각 호출의 결과를 조합할 수 있다.

## 주요 개념 요약

### 반복 패턴과 동점 처리

- 길이 L인 패턴은 `pattern[i % L]`로 반복 구간을 조회한다. 사람 수와 패턴 길이가 고정이면 N개 입력을 비교하는 시간은 `O(N)`, 점수와 패턴의 보조 공간은 `O(1)`이다.
- 최고 점수를 구한 뒤 번호가 작은 순서로 같은 점수의 사람을 추가하면 동점자를 빠짐없이 오름차순으로 반환하므로 정렬이 필요 없다. 최고 점수가 0인 경우도 포함한다.
- `vector` 값 전달은 lvalue 인자로 호출할 때 복사를 만든다. 보조 공간과 입력 복사 공간을 구분하고, 프로그래머스의 제출용 함수 시그니처는 유지한다. 예: [모의고사](./L1_모의고사.cpp).
- 회전 정규화와 DFS의 분기·반환값·참조 전달은 위의 기존 학습 노트를 참고한다.

### 선형 탐색의 효율성과 대안 비교

- 모든 입력을 비교해야 점수를 정확히 계산할 수 있다면 선형 탐색이 적절하다. 고정된 K명의 패턴을 비교하는 비용은 `O(KN)`이며, K가 상수이면 `O(N)`이다. [모의고사](./L1_모의고사.cpp)는 최대 10,000문제에 30,000번의 정답 비교가 필요하다.
- 입력별 순회와 사람별 순회는 같은 비교를 수행한다. 사람별 순회는 인원 증가에 대응하기 쉽고, 입력별 순회는 각 정답을 읽으며 점수를 함께 갱신하기 쉽다.
- 나머지 연산 대신 순환 인덱스를 사용할 수 있지만 복잡도는 같고 경계 분기와 상태 관리가 추가된다. 고정 배열의 동적 할당 절감도 상수 비용 개선이며, 실제 속도 우위는 측정 없이 단정하지 않는다.

### 중복 숫자 순열과 모든 길이 탐색

- 정렬 후 `i > 0 && numbers[i] == numbers[i-1] && !used[i-1]`이면 건너뛴다. 같은 깊이에서 동일 숫자의 선택을 한 번으로 제한하면서, 앞의 숫자를 사용한 뒤에는 같은 숫자를 추가로 선택할 수 있다.
- 선행 0을 제외하면 정수의 표현이 유일해진다. 선행 0을 떼어 얻는 수는 더 짧은 길이에서 생성되므로 빠지지 않으며, 중간의 0은 허용해야 한다.
- 선택할 때마다 현재 후보를 검사하면 모든 길이를 한 DFS에서 처리한다. `value * 10 + digit`과 읽기 전용 참조를 쓰면 문자열 복사·변환을 없애고 재귀 보조 공간을 `O(N)`으로 줄인다. 예: [소수찾기](./L2_소수찾기.cpp).

### 소수 판정과 전처리의 선택

- 2 미만은 소수가 아니다. 합성수는 제곱근 이하의 약수를 가지므로 약수 검사는 후보 x당 `O(sqrt(x))`면 충분하다. `i*i`의 정수 오버플로 가능성은 입력 범위로 확인한다.
- 에라토스테네스의 체는 최댓값 V까지 시간 `O(V log log V)`, 공간 `O(V)`를 사용해 이후 판정을 상수 시간에 처리한다. 후보 개수와 값의 범위를 함께 비교해야 하며 후보가 적다고 체가 항상 유리한 것은 아니다.

### 순열 백트래킹의 상태 공유와 복원

- 방문 배열을 참조로 공유하면 선택 직전에 방문 표시하고 재귀 호출 뒤 해제해야 형제 분기가 독립적이다. 남은 자원처럼 값으로 전달한 상태는 따로 복원하지 않아도 된다. 예: [피로도](./L2_피로도.cpp).
- 현재까지의 개수를 최댓값 초깃값으로 두면 다음 선택이 없는 경우도 같은 반복문으로 처리하므로 종료 확인용 순회를 없앨 수 있다.
- N개 중 가능한 모든 순서를 탐색하면 호출 수는 최악 `O(N!)`이다. 호출마다 N개 후보를 검사하면 시간은 `O(N * N!)`이며, 깊이 N에서 길이 N인 배열을 매번 복사하면 보조 공간은 `O(N²)`, 공유하면 `O(N)`이다.
- 방문 집합만 같으면 남은 자원이 일정한 문제는 비트마스크 DP로 같은 집합의 여러 순서를 합칠 수 있다. 피로도는 `O(N * 2^N)` 시간과 `O(2^N)` 보조 공간으로도 풀 수 있지만 N ≤ 8이므로 백트래킹도 적절하다.

### 사전 순 접두사 탐색

- 접두사를 먼저 처리하고 문자를 오름차순으로 붙이는 DFS는 사전 순으로 단어를 열거한다. 목표보다 큰 접두사는 어떤 문자를 붙여도 목표보다 크므로 가지치기할 수 있다. 예: [모음사전](./L2_모음사전.cpp).
- 빈 문자열은 순위에서 제외하고, 최대 길이의 단어는 센 뒤 확장을 멈춘다. 문자열을 참조로 공유하고 `push_back` / `pop_back`으로 복원하면 깊이별 문자열 복사 공간 `O(L²)`를 `O(L)`로 줄인다. 문자열 비교가 남아 있으면 시간 상한은 `O(L * 5^L)`이다(L은 최대 길이, 모음 수는 5).
- 같은 접두사 아래의 단어 수를 등비수열 합으로 세면 DFS 없이 순위를 계산할 수도 있다. 최대 길이 5의 위치별 가중치는 `781, 156, 31, 6, 1`이며 각 자리의 `모음 인덱스 * 가중치 + 1`을 더한다. `+1`은 현재 접두사 자체를 세는 항이다.
